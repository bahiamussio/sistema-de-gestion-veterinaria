**🐾 El Jardín de Haku - Sistema de Gestión para Veterinarias 🐾**

¡Bienvenido al sistema de gestión de El Jardín de Haku! 🌿🐱🐶 Esta aplicación de consola está diseñada para ayudar a gestionar de forma eficiente los procesos de una veterinaria. Desde el registro de clientes hasta la gestión de ventas, ¡todo en un solo lugar! 💼✨

-----------------------------------------------------

📦 **Características Principales:**


🐕 Registro de Mascotas: Gestiona la información de perros y gatos, incluyendo raza, edad, estado de salud y más.

👩‍⚕️ Gestión de Clientes: Mantén actualizada la información de los clientes. 📇

🛒 Control de Inventario: Administra productos con categorías, precios y cantidades. 📦

💰 Registro de Ventas: Facilita el proceso de venta y actualiza automáticamente el inventario. 💵

🚨 Alertas de Inventario: Recibe notificaciones cuando los productos estén por debajo del stock mínimo. ⚠️

-----------------------------------------------------

🛠️ **Tecnologías Utilizadas:**

Python 3 🐍

Programación Orientada a Objetos (POO) 🔄

Interfaz de consola 🖥️
